A program that takes video input and converts it to ASCII Art (with Save As Image functionality).

**Key Features**
- Takes video input and converts pixels to ASCII code based on colour density
- Draws ASCII characters into a 2-dimensional array / grid, whose cell size can change (larger cellSize means lower resolution).
- 'Space' key takes a screenshot and saves the sketch as a jpg
- Width and height are equal to that of the window
- Dictionary with colour presets, includes: White, Green, Cyan, Magenta, Red, and Yellow
